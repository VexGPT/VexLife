DURABILITY / SYNC POLICY
------------------------
Full-quality current assets are retained in the portable Assortment project bundle even
when the GitHub branch has only this manifest.

Flush queued binary assets to the active Round PR when a DURABLE_VISUAL_CHECKPOINT is
earned, including:
- materially referenced/confirmed/rejected visual;
- fresh-thread or round handoff;
- round closure;
- custody-risk before local/project-only bytes could be lost;
- operational batch point (about 10 indices is a useful heuristic).

Route selection:
  exact practical authorized GitHub binary write -> connector direct
  otherwise -> current Local Operations route -> Relay/qualified host only if required

Do not form a Relay solely because an index number reached 10. Text-only indices do not
need binary ceremony. Conversely, one important image may warrant immediate flush.

CURRENT LIMIT
-------------
The connected GitHub surface exposes Git blob/tree primitives, but this chat environment
does not expose a clean file-reference -> GitHub binary upload handoff for generated
local files. Base64 bridging is possible for small blobs but is not the preferred bulk
path for large visual sets. Until a clean direct binary carriage is available, preserve
the exact asset package + manifest and use one bounded asset-sync Relay/host operation
when a durable binary flush is actually needed.
